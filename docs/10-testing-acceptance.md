# 10 测试与验收

## 文档验收

验收标准：

- `docs/` 下存在核心文档。
- 每个侧边栏大页都有独立页面文档。
- 每个页面文档包含目标用户、入口、布局、织物质感 UI、管理员/普通用户权限、禁用状态、主要交互、接口与数据读写、异步任务、异常状态、验收标准。
- 文档明确数据库是唯一主存储。
- 文档明确上传源文件不放入 Obsidian 自动导出目录。
- 文档明确 FSRS，不使用 SM-2。
- 文档明确异步任务架构。
- 文档明确 Docker 部署方式。

## 后续自动化测试

### 单元测试

覆盖：

- 权限判断。
- 文件名生成。
- Markdown sanitize。
- FSRS rating 映射。
- RAG chunk 切分。
- 导入包 manifest 校验。

### 集成测试

覆盖：

- 上传文本生成笔记。
- 生成卡片并初始化 FSRS。
- 更新笔记后重建向量索引。
- 导出 Markdown 到目录。
- 普通用户写入复习日志。
- 管理员查看普通用户统计。

### E2E 测试

使用 Playwright 覆盖：

- 管理员登录。
- 设置 AI 模型。
- 上传来源文件。
- 生成笔记。
- 查看 Markdown、LaTeX、Mermaid、Markmap 渲染。
- RAG 问答并查看引用。
- 普通用户登录后禁用上传和生成按钮。
- 普通用户完成复习。
- 管理员查看任务日志和用户观看时长。

## 浏览器测试要求

后续实现完成后，必须使用浏览器测试：

- 桌面宽屏。
- 笔记本宽度。
- 手机视口。
- 深浅不同内容长度。
- Markdown 极端内容：长公式、长表格、内嵌 HTML、代码块、思维导图。

视觉检查：

- 文字不被纹理干扰。
- 按钮文字不溢出。
- 禁用态可理解。
- Hover 和 Active 状态自然。
- 页面区域不出现卡片套卡片。

## 关键场景验收

### 上传到笔记

给定管理员上传音频、图片和文本，系统应：

- 创建解析任务。
- 生成可选来源片段。
- 允许管理员勾选来源。
- 生成课堂笔记。
- 自动生成卡片。
- 自动向量化。
- 自动导出 Markdown。

### RAG 问答

给定已生成笔记，用户提问时：

- 系统检索相关 chunk。
- 回答包含引用。
- 找不到来源时明确说明依据不足。

### FSRS 复习

给定到期卡片，用户作答后：

- AI 给出评分建议。
- 用户或系统确认 rating。
- 写入复习日志。
- 更新下一次复习时间。

### 权限

普通用户：

- 可以查看内容。
- 可以 RAG 问答。
- 可以复习。
- 上传、编辑、删除、生成、配置按钮禁用。
- 后端拒绝越权写接口。

### Obsidian 导出

生成内容应出现在：

```text
<导出根>/<学科>/笔记/
<导出根>/<学科>/知识点总结/
<导出根>/<学科>/思维导图/
```

上传源文件不得出现在导出根目录中。

### 数据导入导出

管理员执行导出：

- 创建异步任务。
- 生成压缩包。
- 包含 manifest。
- 不包含明文 API key。

管理员执行导入：

- 校验 manifest。
- 显示冲突策略。
- 写入任务日志。

## 残余风险

- 第三方 OpenAI 兼容服务的参数和错误格式可能不完全一致，需要 provider adapter。
- Docker 容器访问宿主 Obsidian 路径需要用户正确挂载 volume。
- 多模态 OCR 的稳定性取决于模型质量。
- 大文件转写和视频解析需要资源限制，避免阻塞 worker。
