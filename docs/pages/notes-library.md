# 笔记 - 笔记库

## 目标用户

- 管理员：浏览、编辑、删除、重新索引和重新导出笔记。
- 普通用户：只读查看笔记、来源、关联笔记、总结和思维导图。

## 入口

- 路由：`/notes/library`
- 侧边栏：笔记 -> 笔记库

## 页面目标

笔记库是主要阅读界面，重点不是“管理表格”，而是让用户像在 Obsidian 中一样按学科和笔记结构浏览，并在同一屏内完成笔记阅读、元数据查看和关联内容跳转。

## 布局

桌面端采用四区布局：

1. 左侧上方：文件树和过滤区。
2. 左侧下方：当前笔记元数据。
3. 中间：当前笔记主阅读区。
4. 右侧：辅助查看区。

### 左侧上方：文件树和过滤区

内容：

- 学科文件树。
- 类型分组：笔记、错题、复盘、资料衍生笔记。
- 搜索框。
- 过滤器：学科、类型、日期、状态、导出状态、是否已索引。
- 最近打开。

交互：

- 文件树支持展开/折叠。
- 点击笔记节点后中间区域加载笔记。
- 搜索时保留树结构，并高亮匹配节点。
- 过滤器不挤压主阅读区，溢出时在左栏内部滚动。

### 左侧下方：当前笔记元数据

内容：

- 标题。
- 学科。
- 类型。
- 日期。
- 状态。
- 来源文件数量。
- 关联卡片数量。
- RAG 索引状态。
- Obsidian 导出路径。
- 最近更新时间。

交互：

- 点击导出路径复制相对路径。
- 点击来源数量打开来源片段抽屉。
- 管理员可在此触发重新索引、重新导出。

### 中间：当前笔记主阅读区

内容：

- Markdown 渲染后的笔记正文。
- 支持 GFM、受控 HTML、LaTeX/KaTeX、Mermaid、Markmap。
- 管理员可切换阅读/编辑。
- 普通用户固定阅读模式。

交互：

- 标题层级生成页内目录。
- 公式渲染失败时显示原始公式。
- 代码块可复制。
- 图片和附件引用可打开预览。

### 右侧：辅助查看区

内容：

- 页内目录。
- 关联笔记。
- 来源片段。
- 复习卡片摘要。
- 相关知识点总结。
- 相关思维导图。
- 任务状态和错误提示。

交互：

- 点击关联笔记直接切换中间阅读区。
- 点击来源片段在右侧展开原文，不打断中间阅读。
- 点击卡片进入复习卡片详情。

移动端：

- 文件树变为顶部抽屉。
- 元数据变为笔记标题下方折叠区。
- 主阅读区单列。
- 右侧辅助区变为底部抽屉。

## 织物质感 UI 规则

- 文件树使用浅帆布底和细缝线层级连接。
- 当前笔记节点使用柔和布标高亮。
- 元数据区使用更细密的织纹，字号紧凑但高对比。
- 中间阅读区纹理极淡，优先保障长文阅读。
- 右侧辅助区使用轻分隔线，不做卡片套卡片。
- Hover 时只提升局部高光和阴影，不改变行高。

## 管理员权限

管理员可以：

- 查看所有笔记。
- 编辑 Markdown。
- 删除笔记。
- 重新生成复习卡片。
- 重建 RAG 索引。
- 重新导出到 Obsidian。
- 查看完整来源片段。

## 普通用户权限

普通用户可以：

- 查看笔记。
- 查看元数据。
- 查看关联笔记、总结和思维导图。
- 查看来源摘要。

普通用户不能：

- 编辑。
- 删除。
- 重新生成。
- 重建索引。
- 重新导出。

## 禁用状态

普通用户访问时：

- 编辑按钮禁用。
- 删除按钮禁用。
- 重新生成卡片按钮禁用。
- 重建索引按钮禁用。
- 重新导出按钮禁用。
- 禁用按钮 tooltip 显示“需要管理员权限”。

## 主要交互

- 从左侧文件树选择笔记。
- 使用过滤器缩小笔记范围。
- 在中间阅读区查看 Markdown。
- 管理员切换编辑模式并保存。
- 点击右侧关联笔记、来源片段、卡片、总结或导图进行辅助阅读。
- 管理员从元数据区触发重建索引或重新导出。

## 接口与数据读写

读取：

- `GET /api/notes/tree`
- `GET /api/notes`
- `GET /api/notes/:id`
- `GET /api/notes/:id/metadata`
- `GET /api/notes/:id/sources`
- `GET /api/notes/:id/cards`
- `GET /api/notes/:id/related`

写入：

- `PATCH /api/notes/:id`，仅管理员。
- `DELETE /api/notes/:id`，仅管理员。
- `POST /api/notes/:id/cards/regenerate`，仅管理员。
- `POST /api/notes/:id/reindex`，仅管理员。
- `POST /api/notes/:id/export`，仅管理员。

写入表：

- `notes`
- `note_links`
- `jobs`
- `rag_chunks`
- `audit_logs`

## 异步任务

- `ai.generate_cards`
- `embedding.index_note`
- `export.export_note_to_obsidian`
- `export.delete_exported_note`

## 异常状态

- 没有笔记：文件树显示空状态。
- 当前笔记已删除：中间区提示重新选择。
- Markdown 渲染失败：显示原始 Markdown 和错误摘要。
- 索引失败：元数据区显示失败并提供管理员重试入口。
- 导出失败：元数据区显示导出错误。
- 保存冲突：提示刷新、覆盖或另存副本。

## 验收标准

- 桌面端左侧上方为文件树和过滤区。
- 桌面端左侧下方为当前笔记元数据。
- 中间和右侧共同服务于笔记查看，不再使用简单列表加预览布局。
- 管理员可以编辑、重建索引、重新导出。
- 普通用户只能阅读，写操作禁用。
- Markdown、LaTeX、Mermaid、Markmap 能在阅读区渲染。
