# 设置 - 用户与权限

## 目标用户

- 管理员：管理用户、注册策略、查看登录和观看时长。
- 普通用户：查看自己的账号信息。

## 入口

- 路由：`/settings/users`
- 侧边栏：设置 -> 用户与权限

## 页面目标

提供完整登录系统的管理界面，并让管理员掌握普通用户的观看和复习情况。

## 布局

管理员视图：

- 顶部：开放注册开关。
- 主工作区：用户列表和搜索筛选。
- 用户详情：选择用户后在列表下方展开，包含账号信息、角色和状态。
- 活动详情：登录记录、观看时长、复习概览以标签页或抽屉呈现。

普通用户视图：

- 账号信息。
- 自己的登录记录。
- 自己的观看和复习摘要。

## 织物质感 UI 规则

- 用户列表使用细线分隔。
- 角色标签使用布签样式。
- 注册开关使用清晰 toggle。
- 风险操作使用红棕警示缝线。

## 管理员权限

管理员可以：

- 开启或关闭注册。
- 创建用户。
- 禁用用户。
- 修改角色。
- 重置密码。
- 查看登录情况。
- 查看观看时长。
- 查看复习日志汇总。

## 普通用户权限

普通用户可以：

- 查看自己的账号信息。
- 修改自己的显示名。
- 修改自己的密码。
- 查看自己的登录记录。

普通用户不能：

- 查看其他用户。
- 修改角色。
- 查看全体观看时长。
- 查看全体复习日志。

## 禁用状态

普通用户访问此页：

- 用户列表不显示或只显示自己。
- 注册开关不可见或只读。
- 角色管理按钮不可见或禁用。

## 主要交互

- 管理员开启或关闭注册。
- 管理员创建新用户。
- 管理员选择用户查看登录、观看和复习摘要。
- 管理员修改用户角色或禁用用户。
- 普通用户修改自己的显示名或密码。

## 接口与数据读写

读取：

- `GET /api/users/me`
- `GET /api/admin/users`，仅管理员。
- `GET /api/admin/users/:id/activity`，仅管理员。
- `GET /api/admin/users/:id/review`，仅管理员。

写入：

- `PUT /api/users/me`
- `PUT /api/users/me/password`
- `POST /api/admin/users`，仅管理员。
- `PATCH /api/admin/users/:id`，仅管理员。
- `PUT /api/admin/settings/registration`，仅管理员。

写入表：

- `users`
- `sessions`
- `app_settings`
- `view_events`
- `review_logs`
- `audit_logs`

## 异步任务

通常不需要长任务。导出用户活动报告时可创建：

- `export.export_user_activity`

## 异常状态

- 关闭注册后访问注册页：显示注册关闭。
- 修改最后一个管理员为普通用户：禁止。
- 禁用当前登录用户自己：需要二次确认，默认禁止。
- 登录记录过多：分页加载。
- 观看时长 heartbeat 中断：按已收到事件统计。

## 验收标准

- 管理员可以开关注册。
- 管理员可以设置用户角色。
- 普通用户无法查看其他用户信息。
- 管理员可以查看登录情况和观看时长。
- 普通用户可以写入复习日志但不能查看他人日志。
