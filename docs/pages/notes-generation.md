# 学习 - 笔记生成

## 目标用户

- 管理员：上传课堂资料，勾选来源，生成可编辑 Markdown 笔记。
- 普通用户：只能查看页面结构和禁用状态，不能上传或生成。

## 入口

- 路由：`/notes/generate`
- 侧边栏：学习 -> 笔记生成

## 页面目标

把录音、视频、图片、PPT、PDF、文本等资料转成课堂笔记，并自动衔接卡片生成、向量化和 Obsidian 导出。

## 布局

页面分为三步：

1. 上传资料。
2. 勾选来源。
3. 点击生成。

桌面端：

- 顶部为步骤进度条和当前来源概览，可在四个步骤之间切换。
- 顶部为三步进度条，可在上传、勾选来源、点击生成之间切换。
- 主工作区只显示当前步骤的核心操作。
- 解析、转写、OCR、卡片、索引和导出都是后台自动任务，不要求管理员停留等待解析完成才能进入下一步。

移动端：

- 步骤导航折叠为顶部进度条。
- 来源片段使用可展开列表。
- 后台任务详情使用抽屉查看。

## 织物质感 UI 规则

- 上传区域使用帆布纹理虚线缝线边框。
- 拖拽悬停时边框高亮，阴影稍微抬起。
- 勾选来源片段使用布料 checkbox，选中后显示点缀色线迹。
- 生成按钮为布标式主 CTA。
- Active 状态轻微下沉，持续 180-260ms。

## 管理员权限

管理员可以：

- 上传资料。
- 删除尚未生成笔记的来源文件。
- 勾选来源片段。
- 输入生成说明。
- 生成笔记。
- 重新生成。
- 保存生成结果。

## 普通用户权限

普通用户不能使用此页的任何写操作。普通用户访问时：

- 上传区禁用。
- 来源勾选禁用。
- 生成按钮禁用。
- 页面显示“普通用户只能查看已生成内容”。

## 禁用状态

禁用状态必须保留原布局，不把流程步骤隐藏：

- 上传控件禁用并显示“需要管理员权限”。
- 文件删除按钮禁用。
- 来源片段 checkbox 禁用。
- 生成设置表单只读。
- 生成和重新生成 CTA 禁用。

## 支持来源

- 音频：`mp3`、`m4a`、`wav`、`aac`、`ogg`、`flac`。
- 视频：`mp4`、`mov`、`mkv`，需要提取音轨和关键帧。
- 图片：`png`、`jpg`、`jpeg`、`webp`。
- 文档：`pdf`、`ppt`、`pptx`、`docx`。
- 文本：`md`、`txt`。

## 生成设置

管理员可设置：

- 学科，留空则默认由文本AI判断。
- 课程日期，留空则使用当前日期（北京时间）。
- 笔记类型，默认课堂笔记。
- 是否自动生成复习卡片，默认开启。
- 是否生成后自动向量化，默认开启。
- 是否生成后自动导出到 Obsidian，默认开启。
- 本次生成额外说明。

笔记总结额外提示词来自设置页，不在本页重复配置。
生成出的笔记不区分草稿、发布或已整理状态；编辑、索引、导出进度由任务和元数据表达。

## 主要交互

### 上传

1. 管理员拖拽或选择文件。
2. 前端显示文件类型、大小、上传进度。
3. 上传成功后创建解析任务。

### 勾选来源

1. 上传后的解析由后台自动执行，不阻塞页面。
2. 页面展示当前已经可用的 `source_segments`。
3. 管理员勾选参与生成的片段。
4. 低置信片段需要标识，默认不勾选。

### 生成

1. 管理员点击“生成笔记”。
2. 创建 `ai.generate_note` 任务。
3. 任务成功后展示 Markdown 预览。
4. 后台自动创建卡片、向量化、导出任务。

## 接口与数据读写

读取：

- `GET /api/source-files`
- `GET /api/source-files/:id/segments`
- `GET /api/jobs/:id`
- `GET /api/ai/config/status`

写入：

- `POST /api/source-files/upload`，仅管理员。
- `POST /api/source-files/:id/parse`，仅管理员。
- `POST /api/notes/generate`，仅管理员。
- `POST /api/notes/:id/regenerate`，仅管理员。

写入表：

- `source_files`
- `source_segments`
- `jobs`
- `notes`
- `note_sources`
- `review_cards`
- `rag_chunks`

## 异步任务

- `ingest.parse_source`
- `ai.transcribe_audio`
- `ai.ocr_image`
- `ai.generate_note`
- `ai.generate_cards`
- `embedding.index_note`
- `export.export_note_to_obsidian`

## 异常状态

- 必填 AI 模型未配置：禁止生成，提示前往设置。
- 文件过大：上传前拦截并提示限制。
- 解析失败：保留原文件，允许重试。
- OCR 置信度低：片段标记低置信，默认不勾选。
- 转写失败：显示模型错误摘要。
- 生成失败：保留来源选择和输入说明，允许重试。
- 后续卡片或导出失败：笔记仍保存，任务显示失败。

## 验收标准

- 管理员可以按上传、勾选来源、点击生成三步生成笔记。
- 音频、图片、PDF 等来源都有清晰的异步任务状态。
- 生成笔记后自动创建后续卡片、索引、导出任务。
- 普通用户无法上传或生成。
- 上传源文件不写入 Obsidian 导出目录。
- 解析步骤不得设计成需要管理员等待完成后才能继续的阻塞流程。
