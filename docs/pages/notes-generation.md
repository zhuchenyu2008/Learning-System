# 笔记 - 笔记生成

## 目标用户

- 管理员：上传课堂资料，勾选来源，生成可编辑 Markdown 笔记。
- 普通用户：只能查看页面结构和禁用状态，不能上传或生成。

## 入口

- 路由：`/notes/generate`
- 侧边栏：笔记 -> 笔记生成

## 页面目标

把录音、视频、图片、PPT、PDF、文本等资料转成课堂笔记，并自动衔接卡片生成、向量化和 Obsidian 导出。

## 布局

页面分为四步：

1. 上传资料。
2. 解析与来源片段。
3. 生成设置。
4. 结果预览与后续任务。

桌面端：

- 左侧为步骤导航和上传列表。
- 中间为当前步骤工作区。
- 右侧为任务进度、AI 配置状态、来源摘要。

移动端：

- 步骤导航折叠为顶部进度条。
- 来源片段使用可展开列表。
- 任务进度使用底部抽屉。

## 织物质感 UI 规则

- 上传区域使用帆布纹理虚线缝线边框。
- 拖拽悬停时边框高亮，阴影稍微抬起。
- 勾选来源片段使用布料 checkbox，选中后显示点缀色线迹。
- 生成按钮为布标式主 CTA。
- Active 状态轻微下沉，持续 180-260ms。

## 管理员权限

管理员可以：

- 上传资料。
- 删除尚未生成笔记的来源文件。
- 触发解析。
- 勾选来源片段。
- 输入生成说明。
- 生成笔记。
- 重新生成。
- 保存生成结果。

## 普通用户权限

普通用户不能使用此页的任何写操作。普通用户访问时：

- 上传区禁用。
- 来源勾选禁用。
- 生成按钮禁用。
- 页面显示“普通用户只能查看已生成内容”。

## 禁用状态

禁用状态必须保留原布局，不把流程步骤隐藏：

- 上传控件禁用并显示“需要管理员权限”。
- 文件删除按钮禁用。
- 来源片段 checkbox 禁用。
- 生成设置表单只读。
- 生成和重新生成 CTA 禁用。

## 支持来源

- 音频：`mp3`、`m4a`、`wav`、`aac`、`ogg`、`flac`。
- 视频：`mp4`、`mov`、`mkv`，需要提取音轨和关键帧。
- 图片：`png`、`jpg`、`jpeg`、`webp`。
- 文档：`pdf`、`ppt`、`pptx`、`docx`。
- 文本：`md`、`txt`。

## 生成设置

管理员可设置：

- 学科，留空则默认由文本AI判断。
- 课程日期，留空则使用当前日期（北京时间）。
- 笔记类型，默认课堂笔记。
- 是否自动生成复习卡片，默认开启。
- 是否生成后自动向量化，默认开启。
- 是否生成后自动导出到 Obsidian，默认开启。
- 本次生成额外说明。

笔记总结额外提示词来自设置页，不在本页重复配置。

## 主要交互

### 上传

1. 管理员拖拽或选择文件。
2. 前端显示文件类型、大小、上传进度。
3. 上传成功后创建解析任务。

### 解析

1. 页面显示解析任务进度。
2. 完成后展示 `source_segments`。
3. 管理员勾选参与生成的片段。
4. 支持按文件、页码、时间段筛选。

### 生成

1. 管理员点击“生成笔记”。
2. 创建 `ai.generate_note` 任务。
3. 任务成功后展示 Markdown 预览。
4. 后台自动创建卡片、向量化、导出任务。

## 接口与数据读写

读取：

- `GET /api/source-files`
- `GET /api/source-files/:id/segments`
- `GET /api/jobs/:id`
- `GET /api/ai/config/status`

写入：

- `POST /api/source-files/upload`，仅管理员。
- `POST /api/source-files/:id/parse`，仅管理员。
- `POST /api/notes/generate`，仅管理员。
- `POST /api/notes/:id/regenerate`，仅管理员。

写入表：

- `source_files`
- `source_segments`
- `jobs`
- `notes`
- `note_sources`
- `review_cards`
- `rag_chunks`

## 异步任务

- `ingest.parse_source`
- `ai.transcribe_audio`
- `ai.ocr_image`
- `ai.generate_note`
- `ai.generate_cards`
- `embedding.index_note`
- `export.export_note_to_obsidian`

## 异常状态

- 必填 AI 模型未配置：禁止生成，提示前往设置。
- 文件过大：上传前拦截并提示限制。
- 解析失败：保留原文件，允许重试。
- OCR 置信度低：片段标记低置信，默认不勾选。
- 转写失败：显示模型错误摘要。
- 生成失败：保留来源选择和输入说明，允许重试。
- 后续卡片或导出失败：笔记仍保存，任务显示失败。

## 验收标准

- 管理员可以上传至少一种文本来源并生成笔记。
- 音频、图片、PDF 等来源都有清晰的异步任务状态。
- 生成笔记后自动创建后续卡片、索引、导出任务。
- 普通用户无法上传或生成。
- 上传源文件不写入 Obsidian 导出目录。
