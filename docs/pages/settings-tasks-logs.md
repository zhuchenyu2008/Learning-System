# 设置 - 任务与系统日志

## 目标用户

- 管理员：监控后台任务、排查失败、重试或取消任务。
- 普通用户：只能查看与自己相关的少量任务状态，不能管理系统任务。

## 入口

- 路由：`/settings/tasks`
- 侧边栏：设置 -> 任务与系统日志

## 页面目标

提供异步任务系统的可视化控制台，保证上传、生成、索引、导出、导入等长任务可观察、可追踪、可恢复。

## 布局

桌面端：

- 左侧：队列筛选和状态筛选。
- 中间：任务列表。
- 右侧：任务详情、日志、输入摘要、结果摘要。

移动端：

- 任务列表优先。
- 详情以全屏抽屉打开。

## 织物质感 UI 规则

- 队列筛选使用分段控件。
- 状态标签使用布签。
- 日志区域使用高对比等宽字体，背景纹理极淡。
- 失败任务行使用红棕缝线，不使用大面积红色。

## 管理员权限

管理员可以：

- 查看所有任务。
- 查看任务日志。
- 重试失败任务。
- 取消排队或运行中任务。
- 查看审计日志。
- 查看系统健康状态。

## 普通用户权限

普通用户可以：

- 在相关业务页面查看自己的任务状态。

普通用户不能：

- 查看全局任务页。
- 重试系统任务。
- 取消任务。
- 查看系统日志和审计日志。

## 禁用状态

如果普通用户进入该路由：

- 显示无权限提示。
- 不返回任务列表数据。

## 主要交互

- 管理员按队列、状态、创建人和时间筛选任务。
- 管理员点击任务查看输入摘要、结果摘要和日志。
- 管理员重试失败任务。
- 管理员取消排队或可中断的运行中任务。
- 管理员查看审计日志并按实体过滤。

## 任务筛选

筛选项：

- 队列：`ingest`、`ai`、`embedding`、`review`、`export`、`maintenance`。
- 状态：排队、运行、成功、失败、取消。
- 创建人。
- 时间范围。
- 任务名称。

## 接口与数据读写

读取：

- `GET /api/admin/jobs`，仅管理员。
- `GET /api/admin/jobs/:id`，仅管理员。
- `GET /api/admin/jobs/:id/logs`，仅管理员。
- `GET /api/admin/audit-logs`，仅管理员。
- `GET /api/health`。

写入：

- `POST /api/admin/jobs/:id/retry`，仅管理员。
- `POST /api/admin/jobs/:id/cancel`，仅管理员。

写入表：

- `jobs`
- `job_logs`
- `audit_logs`

## 异步任务

本页不创建业务任务，但管理所有任务。

重试时根据原任务类型创建新的 BullMQ job，并在旧任务结果中记录关联的新 job ID。

## 异常状态

- Redis 不可用：显示队列连接失败。
- Worker 无心跳：显示后台处理暂停。
- 日志过长：分页或虚拟滚动。
- 任务输入包含敏感字段：显示脱敏摘要。
- 取消失败：说明任务可能已完成或不可中断。

## 验收标准

- 管理员可以按队列和状态查看任务。
- 失败任务有错误摘要和日志。
- 管理员可以重试失败任务。
- 普通用户不能访问全局任务日志。
- 日志中不出现 API key。
