# 设置 - AI 配置

## 目标用户

- 管理员：配置并测试所有 AI 模型。
- 普通用户：只能看到配置状态，不可查看密钥或修改配置。

## 入口

- 路由：`/settings/ai`
- 侧边栏：设置 -> AI 配置

## 页面目标

保证笔记生成、Embedding、语音转文字、OCR、评分等 AI 能力有明确、可测试、安全的配置。

## 布局

页面按模型用途分区：

1. 笔记生成模型，必填。
2. Embedding 模型，必填。
3. 语音转文字模型，必填。
4. OCR/多模态模型，可选但建议配置。
5. Reranker 模型，可选。
6. AI 评分模型，可选，默认复用笔记模型。
7. 笔记总结额外提示词。

状态区显示：

- 配置完成度。
- 最近测试结果。
- 安全提示。

## 织物质感 UI 规则

- 配置表单使用安静的帆布底。
- 必填状态用细缝线强调，不使用强烈警告色。
- 测试成功使用低饱和绿色织带。
- 测试失败使用红棕色缝线提示。

## 管理员权限

管理员可以：

- 新增和编辑模型配置。
- 保存 API key、base URL、模型名称。
- 测试连接。
- 启用或停用某用途模型。
- 编辑笔记总结额外提示词。

## 普通用户权限

普通用户不能编辑任何配置。普通用户只能看到：

- 哪些能力已配置。
- 哪些能力不可用。

普通用户不能看到：

- API key。
- base URL 的敏感鉴权参数。

## 禁用状态

普通用户访问时：

- 所有输入框只读或脱敏。
- 保存按钮禁用。
- 测试连接按钮禁用。
- API key 只显示“已配置”或“未配置”。

必填模型缺失时：

- 管理员看到可编辑错误提示。
- 普通用户看到“系统 AI 能力未完成配置”。

## 必填校验

以下用途必须填写：

- `note_generation`
- `embedding`
- `speech_to_text`

每项必须有：

- API key。
- Base URL。
- 模型名称。

保存时校验非空。测试失败不阻止保存，但相关功能页必须显示测试失败提示。

## 调试模型建议

本地调试可在设置页录入硅基流动等 OpenAI 兼容服务的 key 和模型名称。仓库文档、示例配置和日志不得包含真实 key。

推荐调试用途：

- 笔记生成：DeepSeek 或 Qwen 类对话模型。
- Embedding：Qwen Embedding 类模型。
- Reranker：Qwen Reranker 类模型。
- OCR：DeepSeek-OCR 或多模态模型。
- 语音转文字：SenseVoiceSmall 或 OpenAI 兼容转写服务。

## 主要交互

- 管理员编辑某用途模型配置并保存。
- 管理员点击“测试连接”验证 base URL、key 和模型名称。
- 管理员更新笔记总结额外提示词。
- 页面保存后刷新配置完成度。
- 普通用户只能查看配置状态，不触发测试。

## 接口与数据读写

读取：

- `GET /api/settings/ai`
- `GET /api/ai/config/status`

写入：

- `PUT /api/settings/ai/:purpose`，仅管理员。
- `POST /api/settings/ai/:purpose/test`，仅管理员。
- `PUT /api/settings/prompts/note-summary`，仅管理员。

写入表：

- `ai_model_configs`
- `prompt_settings`
- `audit_logs`

## 异步任务

连接测试可同步执行短请求，也可以创建：

- `ai.test_model_config`

长文本测试必须异步。

## 异常状态

- Base URL 无效：显示连接失败。
- API key 无效：显示鉴权失败，但不回显 key。
- 模型不存在：显示模型错误。
- Embedding 维度变化：提示需要重建索引。
- 普通用户访问：表单只读。

## 验收标准

- 必填模型缺失时，笔记生成、RAG、转写页面有明确提示。
- 管理员能测试模型连接。
- API key 不会明文显示。
- 普通用户不能修改或查看密钥。
- 笔记总结额外提示词在此页配置。
