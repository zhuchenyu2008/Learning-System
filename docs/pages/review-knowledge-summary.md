# 复习 - 知识点总结

## 目标用户

- 管理员：手动选择笔记范围生成知识点总结。
- 普通用户：阅读已生成的知识点总结。

## 入口

- 路由：`/review/summaries`
- 侧边栏：复习 -> 知识点总结

## 页面目标

把单篇或多篇笔记整理成结构化知识点总结，帮助用户在复习前快速回顾。该页面只保留手动生成和历史总结查看。

## 布局

桌面端分为两个明确部分：

- 查看：左侧紧凑文件树，右侧 Markdown 总结阅读区，元数据和重新生成/重新导出按钮位于正文上方。
- 生成：管理员勾选笔记来源，填写学科、标题、额外提示词、导出和索引选项，然后提交异步生成任务。

移动端：

- 查看和生成通过顶部标签切换。
- 文件树、来源勾选和正文都保持单列，不出现横向溢出。

## 织物质感 UI 规则

- 总结正文像柔软纸布阅读面，纹理要极淡。
- 来源范围使用布签列表。
- 手动生成 CTA 使用缝线圆角矩形。
- 生成状态使用小型织带进度条。

## 管理员权限

管理员可以：

- 手动选择单篇或多篇笔记生成总结。
- 输入本次额外提示词。
- 删除总结。
- 重新生成。
- 重新导出。

## 普通用户权限

普通用户可以：

- 查看总结。
- 查看来源笔记。
- 搜索总结。

普通用户不能：

- 手动生成。
- 删除或重新生成。
- 重新导出。

## 禁用状态

普通用户看到生成区域时：

- 输入框禁用。
- 来源选择禁用。
- CTA 禁用并提示需要管理员权限。

## 手动生成

管理员需要选择：

- 学科。
- 来源范围：单篇笔记、多篇笔记、某学科最近 N 天、某标签集合。
- 额外提示词，可为空。
- 是否生成后自动导出到 Obsidian，默认开启。
- 是否生成后进入 RAG 索引，默认开启。

生成入口只接受本次手动选择的范围和提示词。

## 主要交互

- 点击总结文件树节点打开 Markdown 总结。
- 点击来源笔记跳转到笔记库详情。
- 管理员进入“生成”标签，勾选来源笔记。
- 管理员输入可选额外提示词并提交生成任务。
- 管理员可对生成失败任务进行重试。

## 接口与数据读写

读取：

- `GET /api/knowledge-summaries`
- `GET /api/knowledge-summaries/:id`
- `GET /api/notes?selectable=true`

写入：

- `POST /api/knowledge-summaries/generate`，仅管理员。
- `DELETE /api/knowledge-summaries/:id`，仅管理员。
- `POST /api/knowledge-summaries/:id/export`，仅管理员。

写入表：

- `knowledge_summaries`
- `jobs`
- `rag_chunks`

## 异步任务

- `ai.generate_knowledge_summary`
- `embedding.index_summary`
- `export.export_summary_to_obsidian`

## 异常状态

- 未选择来源：禁止生成。
- 笔记模型未配置：禁止生成。
- 来源笔记过多：提示缩小范围或分批生成。
- 生成失败：保留来源选择和提示词。
- 导出失败：总结仍可在数据库中查看。

## 验收标准

- 管理员可以勾选若干笔记生成总结。
- 手动生成支持额外提示词。
- 页面清晰分为生成和查看两个部分。
- 普通用户只能阅读。
- 总结导出到 `<学科>/知识点总结/`。
