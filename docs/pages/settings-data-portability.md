# 设置 - 数据导入导出

## 目标用户

- 管理员：备份、迁移、恢复数据库。
- 普通用户：不可使用。

## 入口

- 路由：`/settings/data`
- 侧边栏：设置 -> 数据导入导出

## 页面目标

提供安全、可追踪、可恢复的数据库导出和导入能力。

## 布局

页面分区：

1. 创建导出。
2. 导出历史。
3. 导入备份。
4. 冲突策略。
5. 导入导出任务日志。

## 织物质感 UI 规则

- 备份包像档案布袋列表，信息密度高但克制。
- 导入区域使用明确警示缝线。
- 危险操作需要二次确认。
- 任务进度使用织带进度条。

## 管理员权限

管理员可以：

- 创建导出。
- 下载导出包。
- 上传导入包。
- 查看校验结果。
- 选择冲突策略。
- 执行导入。
- 删除旧导出包。

## 普通用户权限

普通用户不能访问导入导出能力。页面可显示只读提示：

```text
数据导入导出需要管理员权限。
```

## 禁用状态

普通用户访问时：

- 创建导出按钮禁用。
- 导入上传控件禁用。
- 导出包下载入口不显示。
- 冲突策略表单禁用。

## 导出内容

导出包包含：

- `manifest.json`
- 用户和角色。
- AI 配置摘要，不含明文 key。
- 来源文件元数据。
- 笔记。
- 复习卡片。
- FSRS 状态。
- 复习日志。
- RAG chunk 元数据。
- 知识点总结。
- 思维导图。
- 任务摘要。
- 可选上传源文件。

导出包不包含：

- 明文 API key。
- Session token。
- 临时文件。
- Redis 队列内部状态。

## 导入策略

导入前必须：

- 校验 manifest 版本。
- 校验文件完整性。
- 展示即将导入的记录数量。
- 检查冲突。
- 要求管理员二次确认。

冲突策略：

- 跳过已有。
- 覆盖已有。
- 新建副本。

默认推荐：跳过已有。

## 主要交互

- 管理员点击“创建导出”并选择是否包含上传源文件。
- 管理员查看导出任务进度并下载完成的备份包。
- 管理员上传导入包并等待预校验。
- 管理员查看 manifest、记录数量和冲突列表。
- 管理员选择冲突策略并二次确认导入。

## 接口与数据读写

读取：

- `GET /api/data/exports`
- `GET /api/data/imports/:id/preview`
- `GET /api/jobs?queue=export`

写入：

- `POST /api/data/export`，仅管理员。
- `POST /api/data/import/upload`，仅管理员。
- `POST /api/data/import/:id/confirm`，仅管理员。
- `DELETE /api/data/exports/:id`，仅管理员。

## 异步任务

- `export.database_export`
- `export.database_import_preview`
- `export.database_import_apply`

## 异常状态

- manifest 缺失：拒绝导入。
- 版本不兼容：显示迁移建议。
- 校验和错误：拒绝导入。
- 存储空间不足：任务失败并提示清理。
- 导入中断：标记部分导入状态，提供恢复或回滚说明。

## 验收标准

- 数据导出创建异步任务。
- 导出包包含 manifest。
- 导出包不包含明文 API key。
- 导入前有预览和二次确认。
- 普通用户无法访问导入导出接口。
