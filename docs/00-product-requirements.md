# 00 产品需求

## 目标

Learning-System 是一个面向课堂学习的 Web 软件，帮助管理员把上课资料变成可复习、可检索、可沉淀的学习资料库。系统必须覆盖完整闭环：

上传资料 -> 解析资料 -> 生成 Markdown 笔记 -> 自动生成复习卡片 -> FSRS 复习 -> RAG 问答 -> 知识点总结 -> 思维导图 -> Obsidian 自动导出。

第一轮实施目标只创建文档，不创建应用代码。

## 目标用户

### 管理员

管理员通常是学生本人、老师、家长或资料维护者，拥有全部能力：

- 上传音频、视频、图片、PPT、PDF、文本等课堂资料。
- 勾选资料来源并生成课堂笔记。
- 查看、编辑、删除笔记、总结、思维导图和复习卡片。
- 配置 AI、Embedding、语音转文字、OCR、Obsidian 导出、注册策略。
- 查看普通用户登录情况、观看时长、复习情况和系统任务日志。
- 执行数据库导入导出。

### 普通用户

普通用户是只读观看者和复习参与者：

- 可以查看笔记、复习总结、思维导图。
- 可以进行 RAG 问答，但问答不能修改知识库。
- 可以进行复习并写入复习日志。
- 不能上传、编辑、删除、生成、导入、导出、配置系统。
- 不单独设计另一套界面；不可用功能在原界面中显示为灰色禁用态。

## 核心场景

### 课堂资料到笔记

管理员上传一节课的资料，可以是：

- 上课录音。
- 上课视频。
- 老师 PPT 或讲义。
- 纸质资料扫描件。
- 手机拍摄的 PPT、黑板、纸质资料。
- 手写或纯文本课堂记录。

系统解析来源后，管理员勾选哪些来源参与生成。AI 自动生成课堂笔记，笔记可以被管理员查看和修改。

### 笔记到 RAG 问答

笔记生成后进入知识库索引。用户可以提出问题，例如“老师之前讲某个知识点时是怎么解释的”。系统基于笔记和解析来源进行检索增强回答，并给出引用来源。

### 笔记到 FSRS 复习

生成笔记时自动生成复习卡片。复习时 AI 根据用户答案打分，系统使用 FSRS 决定下一次复习时间。普通用户允许写入复习日志，管理员可以查看复习情况。

### 笔记到总结和思维导图

管理员可以对单篇或多篇笔记手动生成知识点总结和思维导图。手动生成时可以选择来源范围，并输入额外提示词。

## 视觉需求

Web 端采用“织物质感”设计：

- 背景使用亚麻、帆布、牛仔等织线纹理。
- 主色为温和中性色，少量点缀色用于 CTA、状态和高亮。
- 文字必须保持高对比，避免纹理干扰阅读。
- 边框可以使用缝线、低透明度高光或柔和阴影。
- CTA 可以设计为布标或缝线圆角矩形。
- Hover 时提升高光和阴影，模拟光源移动。
- Active 状态轻微下沉。
- 动效时长控制在 180-260ms。

## 内容与渲染需求

笔记正文以 Markdown 为核心格式，并支持：

- GitHub Flavored Markdown。
- 受控内嵌 HTML。
- LaTeX/KaTeX 数学公式。
- Mermaid 图表。
- Markmap 交互式思维导图。
- 代码块、表格、引用、任务列表、图片和附件引用。

## AI 配置需求

管理员必须填写以下模型配置后，系统才能执行相关 AI 任务：

- 笔记生成模型：OpenAI 兼容 API key、base URL、模型名称。
- Embedding 模型：OpenAI 兼容 API key、base URL、模型名称。
- 语音转文字模型：OpenAI 兼容 API key、base URL、模型名称；同时保留本地模型适配层。
- OCR/视觉理解模型：可以使用多模态模型，例如 GPT、Gemini、DeepSeek-OCR，不要求单独 OCR 模型。

笔记总结额外提示词在设置页配置。知识点总结和思维导图的额外提示词在手动生成时输入，可以为空。

调试阶段可在本地设置页录入硅基流动 key，但文档、`.env.example` 和仓库提交中不得包含真实 key。

## 复习算法需求

复习算法使用 FSRS，不使用 SM-2。参考 `obsidian-spaced-recall` skill 的复习闭环思想，但调度实现以 FSRS 为准。

## Obsidian 需求

系统以数据库为主存储。生成内容自动导出到本地文件夹，供 Obsidian 读取和同步。

导出结构：

```text
<导出根目录>/
  <学科>/
    笔记/
    知识点总结/
    思维导图/
```

文件命名由 AI 生成标题，并追加具体时间：

```text
标题 2026-05-03 20-30.md
```

上传源文件不放到自动导出文件夹里。

## 数据导入导出需求

系统支持数据库导出和导入：

- 导出为压缩包。
- 包含 `manifest.json`、表数据、生成内容、配置摘要和可选上传文件。
- 导入前校验版本、用户权限、数据完整性和冲突策略。
- 导入导出都必须走异步任务。
