# 06 FSRS 复习

## 目标

复习模块把笔记中的知识点转成可抽查卡片，并使用 FSRS 安排每个用户的下一次复习时间。系统不使用 SM-2。

参考：

- Open Spaced Repetition: <https://github.com/open-spaced-repetition>
- ts-fsrs: <https://github.com/open-spaced-repetition/ts-fsrs>
- fsrs4anki: <https://github.com/open-spaced-repetition/fsrs4anki>

## 与参考 skill 的关系

`obsidian-spaced-recall` 提供了“笔记 -> 卡片 -> 到期复习 -> 回写调度”的产品闭环参考，但其中的 SM-2 调度不沿用。本系统保留：

- 独立卡片，不把卡片混入笔记正文。
- 逐题复习。
- AI 判断用户答案。
- 用户可以对判分提出异议。
- 错题或坏卡需要最小修正。

替换为：

- 使用 FSRS 计算 due、stability、difficulty。
- 每个用户拥有独立 FSRS 状态。
- 普通用户可写入复习日志。

## 卡片来源

卡片由笔记生成任务自动创建，也允许管理员从笔记详情页手动重建。

生成原则：

- 一张卡只考一个最小记忆单元。
- 答案边界稳定。
- 可以短答并判对错。
- 对考试、作业或课堂复盘有实际价值。
- 不收录临时比喻、闲聊、过泛主题概括。
- 题面必须明确，不允许只写一个词当问题。

## 卡片类型

### Q/A

格式：

```text
问题 -> 标准答案
```

适合：

- 概念。
- 条件。
- 公式含义。
- 固定搭配。
- 判断依据。

### Cloze

格式：

```text
原句中隐藏一个关键点。
```

适合：

- 定义。
- 公式。
- 固定表述。

## 用户级 FSRS 状态

同一张卡片对不同用户有不同复习状态：

- 管理员自己复习时写入管理员状态。
- 普通用户复习时写入普通用户状态。
- 管理员可以查看普通用户统计，但不能无意覆盖用户状态。

字段见 [03 数据模型](03-data-model.md)。

## 复习流程

1. 用户进入复习页。
2. 系统读取该用户到期卡片。
3. 用户作答。
4. AI 根据标准答案、用户答案和上下文给出评分建议。
5. 系统映射为 FSRS rating。
6. 用户可接受或管理员可人工调整。
7. 写入 `review_logs`。
8. 更新 `fsrs_states`。
9. 展示下一张卡。

## AI 评分

AI 评分输入：

- 题面。
- 标准答案。
- 用户答案。
- 关联笔记片段。
- 评分规则。

输出：

- 是否正确。
- 差异说明。
- 建议 rating。
- 简短讲解。

评分映射：

- 完全忘记或答非所问 -> `again`
- 有方向但关键点错误 -> `hard`
- 基本正确但有小缺漏 -> `good`
- 完全正确且表达清楚 -> `easy`

用户不认可时：

- 可以调整 rating。
- 调整记录写入 `review_logs.manual_score`。
- 审计日志记录调整者。

## 到期统计

复习总览需要显示：

- 当前已到期。
- 今日新增到期。
- 逾期积压。
- 今日完成。
- 正确率。
- 按学科分布。
- 薄弱知识点。

管理员可以切换：

- 仅自己。
- 全体用户。
- 指定用户。

普通用户只能看自己的复习统计。

## 坏卡处理

坏卡包括：

- 题面不清楚。
- 答案边界不稳定。
- 重复卡。
- 卡片价值低。
- 答案错误。

处理策略：

- 普通用户可以标记“题目有问题”，写入反馈。
- 管理员可以编辑、合并、删除卡片。
- 删除卡片时不删除来源笔记。
- 编辑卡片后保留历史复习日志。

## 接口

### GET `/api/review/due`

返回当前用户到期卡片和统计。

### POST `/api/review/answer`

提交答案并创建 AI 评分任务或同步评分结果。

### POST `/api/review/cards/:id/rating`

写入最终 rating，更新 FSRS。

### POST `/api/review/cards/:id/feedback`

提交坏卡反馈。

### POST `/api/admin/review/cards/:id`

管理员编辑卡片。

## 验收标准

- 新笔记生成后自动生成卡片。
- 每个用户复习状态独立。
- 普通用户可以写入复习日志。
- 管理员可以查看普通用户复习情况。
- 调度算法使用 FSRS 字段，不出现 SM-2 参数。
