# 08 安全、认证与权限

## 目标

系统需要完整用户登录体系，角色分为管理员和普通用户。普通用户只作为观看和复习需求，不允许修改、上传或删除内容。

## 认证

支持：

- 邮箱和密码登录。
- 注册开关。
- Session 管理。
- 退出登录。

管理员可以设置是否开放注册。

当关闭注册：

- 注册页显示关闭提示。
- 已有用户仍可登录。
- 管理员仍可手动创建用户。

## 角色

### 管理员

拥有全部权限：

- 上传资料。
- 生成笔记。
- 编辑、删除内容。
- 生成总结和思维导图。
- 管理复习卡片。
- 配置 AI 和 Obsidian。
- 数据导入导出。
- 查看用户登录、观看时长、复习日志。
- 管理用户角色。

### 普通用户

允许：

- 查看笔记。
- 查看知识点总结。
- 查看思维导图。
- 使用 RAG 问答。
- 进行复习。
- 写入自己的复习日志。
- 标记坏卡反馈。

禁止：

- 上传资料。
- 修改笔记。
- 删除内容。
- 生成笔记、总结、思维导图。
- 修改 AI 配置。
- 修改 Obsidian 配置。
- 导入导出数据库。
- 查看其他用户日志。

## 禁用态

普通用户看到不可用功能时：

- 按钮灰色禁用。
- Tooltip 说明“需要管理员权限”。
- 不隐藏入口，保持同一套界面。
- 禁用操作后端仍必须校验，不能只靠前端禁用。

## 观看时长

前端在用户查看内容时发送事件：

- 打开内容。
- 定期 heartbeat。
- 页面关闭或切换。

后端写入 `view_events`，管理员可在用户与权限页查看：

- 总观看时长。
- 按用户统计。
- 按内容统计。
- 最近观看记录。

## 审计日志

必须记录：

- 登录成功和失败。
- 用户创建、禁用、角色变更。
- 内容创建、编辑、删除。
- AI 配置修改。
- Obsidian 配置修改。
- 数据导入导出。
- 任务重试、取消。

审计日志不得记录：

- 明文密码。
- 明文 API key。
- 完整上传文件内容。

## 密码与密钥

- 密码使用强哈希。
- Session token 只存哈希。
- API key 加密存储。
- 前端永不返回完整 API key。

## 接口保护

所有写接口必须：

- 校验登录。
- 校验角色。
- 校验 CSRF 或使用同站 cookie 策略。
- 校验输入 schema。
- 记录审计日志。

## 验收标准

- 普通用户无法绕过前端直接调用上传或生成接口。
- 普通用户复习后能写入自己的复习日志。
- 管理员能查看登录和观看时长。
- 关闭注册后新用户不能自助注册。
- API key 不会出现在页面源码、日志和导出包中。
